# NO MERCY
#### Video Demo:  [youtube](https://www.youtube.com/watch?v=6Px81cJct2w)
#### Description:
![level 3 game](assets\NoMercy!!!.png)
This project is about a game inspired by "No Humanity" (SweatyChair Studio), I once finished this project 3 years ago using C++ and SDL2 library. At that time the code I wrote was too complicated, hardcode everything in a main function and a bunch of if else to make the game works, 90% of the animation, images, object were sketched by me(I used canva and paint exept for the cat boss level at the end, I used free resources on canva), this is the original project: [No mercy](https://github.com/VuVanPhong123/NO-MERCY). So i have written the over 2k lines of C++ into python and using kivy library instead to remake this project. To run this project you can clone this project and run this command:
```python
pip install -r requirements.txt
python project.py
```
You can use debug mode to pass the level if it's too hard by setting the debug mode variable to true:

```python
DEBUG_MODE = True
```
And enjoy the game
